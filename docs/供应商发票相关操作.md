APP: 预制供应商发票

打开APP

![alt text](image/MM/图片134.png)

输入预制发票的公司代码、点击继续：

![alt text](image/MM/图片135.png)

输入发票日期：

![alt text](image/MM/图片136.png)

输入采购订单、回车：

![alt text](image/MM/图片137.png)

点击回车

输入金额，确认无误

![alt text](image/MM/图片138.png)

![alt text](image/MM/图片139.png)

## 修改和过账供应商发票

已经过账的发票不可以修改，只有预制发票可以修改，重复7.3的操作，点击进入预制发票的行项目，点击编辑/过账：

![alt text](image/MM/图片143.png)

过账完成产生供应商发票号
